# 2026-09-18 行動分析ログ

## 1. この日の要点

ひろ氏は、9月初めにAnthropicのIPO期待を主要な投資理由として購入していたSoundHound AIについて、約13％の損失で損切りする方針を明言した。

判断理由は株価下落そのものではない。

AnthropicのIPOマーケティング開始
→ AIサービス企業の比較対象（comps）への期待買い
→ SoundHound AIへの資金流入

という購入時のイベントドリブン仮説が、AnthropicのIPO延期とHoltec NuclearのIPO延期によって維持しにくくなったことを直接の撤退理由としている。

同時に、市場全体に対する認識も変化した。

これまで警戒してきたAI投資過熱や資金調達環境の悪化から一段進み、「株式市場全体から資金が逃げる」という見方ではなく、「資金調達能力によって企業が選別される局面に入った可能性」を中心に置いた。

特に、

利益化までの距離が遠い
＋
継続的な外部資金調達が必要
＋
負債が大きい

企業を高リスク群として扱う判断基準を明示した。

## 2. この日のアクション

### Action 01：SoundHound AIの損切り

ひろ氏は、9月初めに購入したSoundHound AIを「今日のザラ場のタイミングで損切りする」と明言した。

本人説明による購入価格は約7ドル、動画収録時のプレマーケット価格は約6.08ドルで、本人計算では約13％の損失となる。

ただし、提供された動画内では「今日売る」という当日売却方針までは確認できるものの、実際の約定報告までは確認できない。

したがって証拠分類は、

**当日の本人による売却意思・執行予定の表明**

とし、売却完了そのものは後続ログで確認する必要がある。

### 売却理由

本人が明示した理由は、

> 「株価が下がってること以上に、買った時の根拠が崩れた」

というものだった。

購入時には、

Anthropic IPO
→ AIサービス企業のcompsに期待買い
→ SoundHound AIも再評価
→ 高いショート比率によるショートカバー

という短期イベントトレードを想定していた。

AnthropicのIPOが延期された後も、Holtec NuclearのIPOが成功すれば「AI関連のIPO需要が残っている」という代替確認材料になると考え、保有理由を残していた。

しかしHoltecもIPOを延期したことで、その代替根拠も失われた。

このため、

Anthropic IPO延期
→ Holtec IPO延期
→ AI関連IPO需要への疑念
→ SoundHound保有仮説の弱体化
→ 損切り

という意思決定経路になっている。

## 3. この日の状態変化

### State Change 01：AI関連企業を一括して見る状態から「資金調達力による選別」へ

### Before

AI投資の過熱、設備投資負担、金利、IPO市場などを警戒しながらも、個別のイベントによってAI関連企業へ資金が流入する余地は残っていると判断していた。

SoundHound AIについても、企業単独の長期的な利益成長を主要理由として保有していたのではなく、Anthropic IPOをきっかけとするAIサービス企業への期待買いを利用するイベントトレードとして位置づけていた。

### New Information

第一に、Anthropicの9月IPOという当初想定が延期された。

第二に、Anthropic延期後の代替確認材料として見ていたHoltec NuclearのIPOも延期された。

第三に、すべてのIPOが停止したわけではなく、他業種を含むIPO案件は予定を維持していると本人は観測した。

第四に、FOMCが0.25％の追加利上げを実施し、外部資金への依存度が高い企業にとって資金調達環境がさらに厳しくなると判断した。

### After

ひろ氏は、市場全体が一律に崩れることよりも、

**「お金が集まる企業」と「お金が集まりにくい企業」の選別**

が始まった可能性を重視する状態へ移った。

選別基準として新たに明示されたのは、

1. 現在の事業でキャッシュを生み出せているか
2. 今後の成長に継続的な外部資金調達を必要とするか
3. 現在の株価が遠い将来の利益をどこまで先取りしているか

である。

さらに、追加資金調達なしでは「1～2年程度しか会社が持たない」企業を、資金調達環境の変化に敏感な企業として足切り候補にするという具体的な判断基準を提示した。
