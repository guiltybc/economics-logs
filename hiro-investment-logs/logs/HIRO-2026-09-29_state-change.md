# 2026-09-29 行動分析ログ

## 1. この日の要点

この日は具体的な新規購入・売却の実行報告ではなく、**市場環境に対する警戒度とポジション管理条件の変更**が確認された。

ひろ氏は米国の長期金利上昇を「資本の値段が高くなった」と捉え、高PER企業に対して投資家が要求する成長の裏付けが厳しくなる局面に入ったと判断した。

さらに、IPOの延期・中止や上場後の値動きを単独のIPO案件として見るのではなく、

長期金利上昇  
→ 資本コスト上昇  
→ IPO市場悪化  
→ 社債・融資・プロジェクトファイナンスへの波及  
→ AIデータセンター建設条件悪化  
→ 建設延期・規模縮小  
→ GPU・HBM需要見通し悪化  
→ NVIDIA・SK hynix等の利益期待低下  
→ NASDAQ・S&P500等への波及

という資金調達側から実体投資・企業利益へ伝播する経路を提示した。

そのうえで、

1. 長期金利が高水準に定着・さらに上昇する
2. IPO市場の悪化が続く
3. 雇用統計が強く、さらに金利上昇圧力がかかる

という複数条件が悪い方向へ揃った場合、「もう1段階守りを強める」「コアのポートフォリオも落とす必要が出てくる」と述べた。

実際の売却は確認できないものの、**防御行動へ移る条件が以前より具体化した状態変化**として記録する。

`1 ÷ 20 = 5%`

`1 ÷ 0.055 ≒ 18.2`

ただし、これは株式の適正PERが機械的に国債利回りの逆数へ収束するという意味ではなく、本人も「雑な説明」として提示している。

## 11. AIによる状態変化の妥当性評価

今回の状態変化で注目すべき点は、株価指数だけを見るのではなく、**資金調達環境から実体投資へ波及する経路を段階的に観測しようとしていること**である。

特に、

IPO  
→ クレジット  
→ プロジェクトファイナンス  
→ データセンター建設  
→ GPU/HBM発注

という順序を置いたことで、仮説に反証可能性が生まれている。

AIデータセンター投資が実際に縮小していない段階で「AIバブル崩壊」と断定せず、中間変数を確認してから防御行動を強める構造も一貫している。

一方で、今回の判断には重要な観測誤差が含まれている。

とりわけ中心的な状態変化トリガーとして提示された**米10年債5%超えが公的データで確認できない**点は軽視できない。

また、IPO市場悪化の証拠として使用したADARxの値動きについても、当時の実際の市場データと逆方向の説明が含まれる。

したがって、

**因果モデルそのもの**

と、

**そのモデルへ入力された観測データ**

を分離して評価する必要がある。

因果モデルには追跡可能な中間変数が設定されている一方、今回の動画では複数の入力データに事実確認上の問題がある。

今後、このタイプの判断を設計図化する場合は、

**市場データ確認 → 支配変数認定 → 因果ネットワーク形成 → 行動条件設定**

という順序のうち、最初の市場データ確認を独立した監査工程として扱う必要がある。
