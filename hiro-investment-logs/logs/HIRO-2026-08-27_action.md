2026-08-27 行動分析ログ
1. この日のアクション
ひろ氏は8月27日、性格の異なる二つの投資アイデアを提示した。

一つは、4月4日にも推奨していたブラジルを中心とする中南米・新興国株への継続的な強気姿勢である。

ブラジル株ETF「EWZ」とメキシコ株ETF「EWW」を再び取り上げ、米長期金利の低下、新興国ファンドへの資金流入、米国株との大きなバリュエーション格差を根拠に投資妙味があると判断した。

もう一つはSoundHound AI（SOUN）である。

こちらはMicrosoftやSQMとは投資理由が異なる。

ひろ氏はSoundHound AIについて、会社そのものが長期的に大きく成長すると考えて買うのではないことを明示している。

9月に想定していたAnthropicのIPOなどを契機にAIサービス企業へ資金が向かった場合、時価総額の小さいSoundHound AIには相対的に大きな株価インパクトが生じる可能性がある、という短期的な資金フローを狙ったアイデアだった。

2. Action 01：ブラジル・中南米株の継続推奨
対象: ブラジル株・メキシコ株
具体的商品: EWZ / EWW
行動: 継続推奨
行動強度: 明確な推奨
自己保有: 本発言からは確認できない
時間軸: 中期
中心テーマ: 米金利低下・新興国への資金流入・割安性・AI集中からの分散

この時点で新しく加わった根拠
4月4日のブラジル推奨では、中東情勢とホルムズ海峡の供給制約を起点に、

資源・食料を供給できる国は、輸入国より相対的に有利

という地政学・資源面の論理が中心だった。

8月27日には、同じブラジルを推奨しながら説明の中心が変化している。

本人が新たに重視したのは、

米長期金利の低下
→ 新興国へ資金が向かいやすくなる

という金融環境だった。

さらに、8月22日前後の報道として新興国ファンドへ約15.7億ドルの資金が流入したことを挙げ、自分のシナリオが実際の資金フローとして現れ始めたと判断している。

EWZのPERについても約11.29倍とし、米国株全体を表すVTIの約25.37倍と比較した。

したがって8/27のブラジル投資は、

安いから買う

だけではなく、

安い市場に実際に資金が入り始めたことを確認して買う

という論理になっている。

3. 4/4ブラジル仮説から何が変わったか

4月4日の中心仮説は、

中東危機
→ エネルギー・食料供給不安
→ 資源国の相対優位
→ ブラジル

だった。

同時に、

米景気減速
→ 将来のFRB利下げ
→ ドル安
→ 新興国への資金移動

という第二経路も本人は想定していた。

8月27日時点では、後者に近い材料をより重視するようになっている。

米長期金利が低下し、新興国ファンドへの資金流入も観測され始めたためである。

したがって4/4→8/27は、ブラジルという結論を維持したまま同じ説明を繰り返したものではない。

4/4に置いた複数シナリオのうち、

「米国から新興国へ資金が移動する」

という経路について、本人が新しい観測材料を追加したものと整理できる。

このため本ログでは thesis_update とする。

4. ブラジルについて本人が認識していたリスク
ひろ氏は、ブラジルが割安なのには理由があることも認めている。

本人が挙げたのは、政治・財政リスク、商品市況への依存、大統領選挙、中国経済への依存などだった。

したがって、

低PER＝安全

とは考えていない。

本人の判断は、

低いバリュエーション
＋ 実際の資金流入
＋ 米金利環境の改善

が同時に見えたため、割安さを投資対象として評価できるようになったというものだった。

この点は4/4より判断条件が増えている。

5. AIによるブラジル投資の当時点評価
※8月27日以降のEWZ・EWWの値動きは評価に使用しない。

この判断で比較的強いのは、「割安だから買う」だけで終わっていない点である。

新興国株は長期間低いPERで放置されることがあり、米国株とのバリュエーション格差だけでは上昇開始の時期を判断できない。

そこへ金利環境とファンドフローを追加し、

価格の安さ＋資金移動

を組み合わせているため、4/4より投資判断の確認条件は具体化している。

またブラジル株は米大型テックとはセクター構成が大きく異なるため、AI・Big Techへの集中を避ける分散先として検討する合理性もある。

一方、米金利低下がそのままブラジル株上昇につながるとは限らない。

金利低下の理由が米景気の深刻な悪化であれば、商品需要や世界的なリスク選好が悪化し、新興国株に逆風となる可能性もある。

したがって、

米金利低下 → 新興国株高

という単独の因果より、

米金利低下＋ドル環境＋実際の資金流入＋ブラジル固有要因

を継続確認する必要がある。

総合すると、4/4より根拠が市場データによって補強された投資判断と評価できる一方、世界景気悪化時の新興国特有のリスクは残っている。

7. SoundHound AIを選んだ中心仮説
ひろ氏は、NVIDIAのような巨大企業について、好決算が出たとしても時価総額がすでに極めて大きいため、さらに株価を何倍にもするには非常に大きな買い需要が必要だと考えた。

一方、SoundHound AIの時価総額は約30億ドル規模。

本人はこれを「プール」の大きさに例え、

巨大なプールへ資金が入っても水位はあまり上がらないが、小さなプールなら同じ規模の資金でも水位が大きく動く

と説明した。

9月に想定していたAnthropic関連の大型資金調達・IPOなどによってAIサービス企業への注目が高まり、大型AI銘柄から周辺の小型AI銘柄へ資金が波及すれば、SoundHound AIのような小型株には大きな価格変化が起こり得るという仮説である。

したがって、

AI大型イベント
→ AIサービス領域への注目
→ セクター内資金移動
→ 小型AI株へ資金流入
→ SOUNの株価変動拡大

という経路を想定している。

8. Microsoftとの戦略上の違い
← 2026-07-31.md
relation: strategy_contrast

MicrosoftとSoundHound AIは、どちらもAI関連銘柄だが、ひろ氏が投資対象とした理由はほぼ逆である。

7/31のMicrosoftでは、

Azure成長
→ AI売上
→ CAPEX
→ FCF
→ 受注残
→ 将来売上

という企業ファンダメンタルズを比較した。

8/27のSoundHound AIでは、そのような長期的企業価値を主要な判断材料にしていない。

こちらは、

イベント
→ 市場の注目
→ 資金移動
→ 小型株の価格反応

を狙う。

したがって現時点では、

Microsoft＝企業価値・投資回収力を買う

SoundHound AI＝市場参加者の資金移動を買う

という二種類の投資ロジックが観測される。

同じ「AI株」という分類だけで一つの投資ルールにまとめるべきではない。

9. AIによるSoundHound AIアクションの当時点評価
総合評価：短期需給トレードとしては成立するが、因果連鎖の不確実性が高い
企業の長期成長性ではなく、イベントを契機とした資金フローを狙うこと自体は短期トレード戦略として成立する。

また本人が最初から、

長期企業価値への投資ではない

と投資理由を限定している点は重要である。

これにより、企業業績が長期的に伸びるかという問題と、短期間に資金が流入するかという問題を混同していない。

一方、「小型株だから少ない資金で大きく上がる」という説明には単純化がある。

時価総額の増加額は、その金額と同額の現金が市場へ流入したことを意味しない。株価は限界的な売買価格によって決まり、流動性、浮動株比率、売り注文の厚さ、ショートポジション、オプション市場などにも左右される。

したがって、

時価総額が小さい → 必ず少額の資金流入で大幅上昇する

とは言えない。

より正確には、時価総額が小さく流動性の低い銘柄では、需給変化による価格弾力性が大型株より高くなる場合がある、と整理すべきである。

さらに最大の不確実性は、

AI関連大型イベントが起こる
→ SOUNへ資金が向かう

という接続部分である。

AIサービス領域が注目されても、資金がSoundHound AIを選択する保証はない。

このためMicrosoftの7/31投資より、仮説に含まれる中間ステップが多く、予測誤差も大きいトレードと評価する。

10. NVIDIAを買わなかったことの扱い
この日の発言ではNVIDIAについて、

「決算前に決め打ちで買わない」 「好決算を確認してからでも遅くない」

という判断も示している。

ただし本ログではNVIDIAを独立したアクションとして登録しない。

本ログの目的は、本人が実際に行った売買または明確に提示した投資対象を蓄積することであり、「買わない」という判断をすべて記録するとログ量が急増するためである。

ただしSoundHound AIを選択した背景として、

巨大AI銘柄を追わず、より小さな資金プールへ向かう

という比較判断に必要な範囲では保存する。

11. 9月に対する市場シナリオ
8/27時点で、ひろ氏は9月のAI関連大型ディールを市場全体の需給イベントとして警戒していた。

大型IPOや資金調達が行われれば、市場に存在する投資資金を新規案件が吸収し、既存のAI・Big Tech株に需給面の負荷がかかる可能性があると考えていた。

一方、そのイベントが通過した後、すべての資金が再び大型AI株へ戻るとは限らないとも考えた。

その場合、

割高な米AI株 → 割安なブラジルなどの新興国

というローテーションが起きる可能性を想定している。

興味深いのは、同じ「AI関連大型ディール」を、

SoundHound AIには短期的な資金流入機会

として、

ブラジルには中期的な資金ローテーションの契機

として使っていることである。

一つの市場イベントから複数の時間軸の投資機会を導いている。
