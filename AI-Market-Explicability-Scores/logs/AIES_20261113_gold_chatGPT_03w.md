＞週次Bってなんだっけ？

週次Bとは、G方式で「1週間の指標変化量」を点数に換算するための基準値です。( ﾟ∀ﾟ)

AIESでは、次の計算式を使っています。

Y=5\\times\\frac{\\Delta I}{B}\\times S

* ΔI：実際の指標変化量

* B：基準となる変化量

* S：金価格への理論的作用方向（＋1または−1）

例えば、米10年実質金利の場合です。

|       | 日次B（設定済み）    | 週次B（未設定） |
| ----- | ------------ | -------- |
| 基準変動量 | 5bp          | 仮に15bp   |
| 実際の変化 | +28bp        | +28bp    |
| 計算結果  | −28 → −10に制限 | −9.3     |

※週次15bpは説明用の仮定です。

つまり、1日で28bp動くのと、1週間で28bp動くのでは、変化の大きさの評価が違うということです。

現在のVer3.1-T0には日次Bしかありません。

そのため、週次や月次で実験するには、それぞれの期間に対応したBを設定する必要があります。

私としては、過去1年程度の各指標の週間変化量を調べ、その分布から週次Bを決める方法が有力だと思います。

そうすれば、金価格の結果を一切参照せず、客観的な基準を作れます。

ただし、Bは金価格への影響力ではなく、各指標の変化の大きさを測る物差しです。ここはAIESの設計上、重要な区別ですね。

＞月でも同じだね

そうです！( ﾟ∀ﾟ)

月次Bも週次Bと同じ考え方で設定する必要があります。

つまり、AIESでは各指標について、3種類のBを持つことになります。

| 観測期間 | 基準変動量      |
| ---- | ---------- |
| 昨日今日 | 日次B（既存のT0） |
| 1週間  | 週次B（未設定）   |
| 1ヶ月  | 月次B（未設定）   |

例えば実質金利なら、過去の実測データから日次・週次・月次それぞれの典型的な変動幅を求めます。

ここで重要なのは、日次Bを単純に5倍、20倍してはいけないことです。

変動幅は必ずしも時間に比例しません。

さらに、AIESの設計では一つ注意点があります。

Bを期間ごとに設定すると、Y＝5が意味するのは「その期間における基準的な変動幅」になります。

つまり、日次Y＝5と月次Y＝5は、同じ絶対変化量を意味しません。

これは欠陥ではありませんが、期間をまたいで比較するときには注意が必要です。

私なら次の改訂では、日次・週次・月次のBを一括して統計的に設定し、独立した換算定数表T1として管理する方向を提案します。

そうすれば、Ver3.2の基本仕様を変更せずに、3種類の観測期間すべてでG方式を実行できるようになります。
